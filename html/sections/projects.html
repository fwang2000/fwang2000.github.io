    Tournament Scheduling SAAS

    January 2022 - May 2022

    click to open

    GameSetMatch

    Description

    A full-stack tournament hosting and scheduling web app, built in a team of 6 as a sponsored capstone project with Amazon. I owned the scheduling algorithm, modeling user matching as bipartite graph matching over player availabilities, then applied a greedy maximum-independent-set pass on the transformed graphs to generate schedules that supported availability, skill, and multiple tournament formats. I tuned it to schedule the full 300-user base against peak tournament thresholds in under 4 seconds, and also contributed to the MySQL schema and React frontend.

    Tools

    • Backend: Java, Spring Boot, REST APIs, MySQL schema design
    • Frontend: React, Firebase Authentication
    • Algorithms: bipartite graph matching + greedy maximum independent set for constraint-based scheduling
    • Cloud / deployment: AWS (Amplify frontend hosting, MySQL-backed service)
    • Team & process: 6-person team, waterfall SDLC with full documentation (project plan, design docs, test plan) and sponsor delivery
